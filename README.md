# Healthcare-Analytics-Project

## Project Overview

Developed a Healthcare Analytics Dashboard project using **Excel, Power BI, Tableau, and SQL** to analyze patient, doctor, diagnosis, and treatment data.

This project demonstrates end-to-end data analytics workflow including data querying, KPI generation, dashboard development, and healthcare insights visualization.

---

## Tools Used

* Microsoft Excel
* Power BI
* Tableau
* SQL

## Key KPIs

* **Total Patients:** 10,000
* **Total Doctors:** 1,000
* **Average Age of Patients:** 48
* **Average Patients Per Doctor:** 10
* **Follow-Up Rate:** 49.84%
* **Average Treatment Cost:** ₹524.51
